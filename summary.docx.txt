House Price Prediction – Project Summary

Objective:

The objective of this project was to build a machine learning model capable of predicting house prices based on various housing features. The project involved data preprocessing, exploratory data analysis, model training, evaluation, and visualization.

Dataset:

The Housing dataset containing 545 records and multiple housing-related features was used. Data cleaning included handling missing values, removing duplicates, and converting categorical variables into numerical format.

Models Used:

1. Linear Regression
2. Random Forest Regressor

Results:

Linear Regression achieved the best performance with:

* MAE: 970,043
* RMSE: 1,324,507
* R² Score: 0.653

Random Forest achieved:

* MAE: 1,021,546
* RMSE: 1,400,566
* R² Score: 0.612

Key Findings:
The most influential factors affecting house prices were area, bathrooms, stories, and air conditioning. Properties with similar sizes often showed different prices due to amenities and location-related factors.

Conclusion:
The Linear Regression model provided the most accurate predictions for this dataset. Machine learning can effectively assist real estate businesses in estimating property values and identifying important pricing factors.
